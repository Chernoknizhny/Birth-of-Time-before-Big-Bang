# The Birth of Time before the Big Bang
## Рождение времени до Большого взрыва

**Автор:** E. V. Chernoknizhny (Evgeny Chernoknizhny), Independent Researcher
**ORCID:** [0009-0007-2558-9172](https://orcid.org/0009-0007-2558-9172)

## О работе

Исследование предлагает гипотезу о возникновении времени до Большого взрыва.
Время рассматривается не как фундаментальная основа, а как эмерджентная
величина, порождаемая корреляциями между подсистемами.

Ключевые результаты версии 10.3:

- Структура соотношения t = α·n_ev·C выводится из соотношений Онсагера
  и кинетической теории; нормировка фиксирует β = 8/3 без свободных параметров.
- Две численно проверяемые величины: dn_ev/dt = 5,0·10²⁴ м⁻³с⁻¹ и
  интерферометрический предел на универсальный канал декогеренции
  η ≤ 6,8·10⁻²⁵ (эксперимент Kovachy et al., 2015).
- Предел независим от декогеренции на горизонтах
  (Danielson–Satishchandran–Wald): разведение ≥ 158 порядков.
